## Stellar Wave

This project participates in the [Stellar Wave](https://www.drips.network/wave/stellar) program. Issues are tagged with complexity levels:

- `complexity:trivial` — 100 points
- `complexity:medium` — 150 points
- `complexity:high` — 200 points

Browse [open issues](https://github.com/stellar-crucible/soroban-testkit/issues) to find tasks that match your skills and interests.
